Before you jump in

A few things
to know.

Do I need an API key?

For a cloud provider, yes: add your own key in Settings. An all-local setup can run without a cloud API key once its models and components are installed.

Can I use it offline?

Yes, with local speech recognition, a local language model and local speech synthesis. Download the models first. Cloud providers and online tools still need an internet connection.

Where do my conversations go?

Saved history lives on your computer. Cloud providers receive the content sent to their models; connected tools receive the data needed for their actions. You choose which ones to use.
