MAKE YOURSELF AT HOME

One conversation.
More ways to be there.

01 / A THOUGHT, IN ANY FORM

Start with what
you have in mind.

Type a question, add a photo, or dictate a draft. There’s space to think before you hit send.

  • Choose an image, take a photo, paste or drop it.
  • Review your attachments and dictated text.
  • An input that grows with your message, up to eight lines.
Image understanding depends on your selected model.
02 / LET THE CONVERSATION FLOW

Some things are
easier out loud.

Tap the waveform and start talking. Your transcript stays in view, with quiet controls and room for the response.

  • Realtime speech, or your own STT → LLM → TTS setup.
  • Mute, interrupt and hang up from the conversation.
  • Models, tools and usage details in a panel when you need them.
Hanging up keeps the thread. Continue it later.
03 / PICK UP WHERE YOU LEFT OFF

A place for
every conversation.

A weekend plan, a new project, a passing thought. Each thread keeps its context, images and tool results together.

  • Your 30 most recent conversations, a click away.
  • Search all titles, rename a thread, or delete it.
  • Reopen saved results without running the tool again.
History is stored locally. You can turn saving off in Settings.

WHAT YOU SEE HERE

Try the development build

The interface above is on main. Start from source with Python 3.12+ and uv.

Terminal · new checkout 
git clone https://github.com/roomkit-live/roomkit-ui.git
cd roomkit-ui
uv sync --extra all
uv run --no-sync python -m roomkit_ui

Already have a checkout? See the source setup guide for optional components. all excludes some large local voice backends.
